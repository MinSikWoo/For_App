지금까지 한 내용을 정리해줘 (결정된 것 / 안 정해진 것 / 다음 할 일)
결정된 것은 claude.md에 반영하고 깃허브에 저장해줘.

이 저장소는 클라우드(휴대폰 앱)에서도 작업한다. 클라우드 컴퓨터는 작업이 끝나면 사라지므로 메모리 기능에 저장한 내용은 남지 않는다. 그래서 저장은 claude.md에 하고, 반드시 커밋하고 푸시한다.

**이 저장소는 공개 저장소다.** 누구나 볼 수 있다. claude.md에 아래 내용은 절대 적지 않는다.
- 대외비, 회사 내부 자료, 고객 정보
- 개인정보 (이름, 연락처, 주소 등)
- 비밀번호, API 키, 접속 정보
- 적어도 되는지 애매하면 적지 말고 대표에게 물어본다.

저장 순서:
1. 정리 내용을 먼저 머릿속으로 만들어 둔다. 파일은 아직 건드리지 않는다.
2. `git pull --rebase`로 최신 내용을 받는다. 다른 세션이 방금 저장한 내용이 있을 수 있다.
3. claude.md를 지금 다시 읽는다.
4. claude.md 맨 아래 `## 결정사항 (wrapup)` 구역에 날짜와 함께 덧붙이거나 고친다. 구역이 없으면 만든다. 파일 전체를 새로 쓰지 말고, 다른 세션이 넣은 내용은 지우지 않는다. 내용이 서로 충돌하면 둘 다 남기고 대표에게 알린다.
5. claude.md만 커밋한다. 커밋 메시지는 `wrapup: 결정사항 정리 YYYY-MM-DD`로 한다.
6. 지금 작업 중인 브랜치로 푸시한다. 푸시가 거절되면 `git pull --rebase` 후 다시 푸시한다 (최대 3번). 그래도 실패하면 대표에게 알린다.
7. 저장 결과(어느 브랜치에 저장했는지 포함)를 대표에게 짧게 보고한다.
